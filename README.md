# VetDiet · 환자 식이 급여량 프로그램

강아지·고양이 성체 외래 환자의 로얄캐닌·힐스 사료 후보 확인 및 급여량 계산 프로그램입니다.

## 실행

Windows에서는 `프로그램 실행.cmd`를 더블클릭하세요. Node.js가 설치되어 있어야 하며, Codex의 번들 Node.js 환경도 지원합니다.

다른 환경에서는 다음 명령을 실행한 뒤 <http://127.0.0.1:4173/>에 접속합니다.

```sh
cd patient-diet
node serve.cjs
```

외부 패키지 설치 없이 실행하며, 환자 기록은 사용한 브라우저의 로컬 저장소에 저장됩니다.

## 기능과 범위

- 로얄캐닌·힐스 제품 38개의 출처 및 제품 자료
- 종·체중·연령·식이 목표·질환 용도에 따른 후보 필터
- 하루/한 끼 급여량, 간식 열량 차감, 두 제품 혼합 급여 계산
- 수의사 검토 후 기록 저장, 진료 요약, 안내문 인쇄, 백업/복원
- 수술·기본 환자 정보에 따른 금식 시간·첫 급여 시점·로얄캐닌/힐스 식이·급여량 추천과 안내문
- 신장·요로·소화기·췌장염·식이 이상반응·당뇨·비만의 질환별 식이법

일상 급여 계산은 성체 외래 환자용입니다. 수술 메뉴는 수술별 근거와 초기 급여 예시를 제공합니다. 질병 단계·검사값 자동 해석과 성장기·임신·수유의 완전한 영양 계획, 재급식·경관 급여 프로토콜은 지원하지 않습니다. 실제 제품 포장과 열량을 대조하고, 수의사가 제품 적합성과 목표 열량을 검토해야 합니다.

## 아이패드 웹앱

아이패드 Safari에서 배포 링크를 연 뒤 본인 계정으로 로그인하고, 공유 → 더 보기 → 홈 화면에 추가를 선택하세요. 표시되면 ‘웹 앱으로 열기’를 켭니다. 홈 화면의 VetDiet 아이콘으로 실행할 수 있습니다.

배포 링크: https://vetdiet-leeboy-ipad.cooltapir2.chatgpt.site

기록은 각 기기·브라우저의 저장 공간에 있으며 자동 동기화하지 않습니다. PC에서 급여 기록과 수술 기록을 각각 백업하고 아이패드 앱에서 각각 불러오세요. Safari와 홈 화면 앱의 저장 공간도 다를 수 있습니다. ‘앱 준비 완료’ 후 기본 계산·등록 자료 조회는 연결 없이 이용할 수 있습니다. 제조사/근거 링크·로그인·업데이트에는 인터넷 연결이 필요합니다.

Sites 배포 사본은 `ipad-site/`(Git 제외)에 있으며 `.openai/hosting.json`의 기존 project_id를 재사용합니다. 업데이트는 수정된 `patient-diet/dist/`를 이 사본에 반영하고 같은 Site의 소스 동기화·패키징·비공개 배포 절차를 사용합니다. 서비스워커의 CACHE 버전도 갱신합니다.
